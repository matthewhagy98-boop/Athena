# AI Synthesis Narratives Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate grounded, citation-checked narrative syntheses for a user-selected comparison of papers or topics, and render them in the panel sub-project A deliberately left empty on the Compare page.

**Architecture:** A new `synthesis/` package owning three tables. A content-addressed cache keyed on the exact member set plus prompt and model version, invalidated by a fingerprint over member state. Generation goes through the existing forced-tool LLM helper, and every response is structurally validated and citation-checked before it is ever stored or shown — an unvalidated narrative is discarded, never displayed.

**Tech Stack:** Python 3.12, SQLAlchemy 2.0 + Alembic (same DB and `Base` as `evidence_engine`), the existing `anthropic` client wrapper, FastAPI, React + TanStack Query.

## Global Constraints

- **A narrative is never shown unless it passed validation.** Structural validation, citation resolution, and the citation-density check all run before persistence. On failure the row is stored with `status='failed'` and no narrative text (spec §11, §14.3).
- **Citation density must be ≥ 0.6** — at least 60% of claims carry a resolvable citation — or the whole synthesis is rejected with `failure_reason='citation_density'`. An empty `claims` array is an automatic rejection with `no_valid_claims` (spec §14.3).
- **Citations are member indices, not free text.** The model returns integer indices into the member list; any index outside range is dropped before the density check (spec §11).
- **The cache key is content-addressed**: SHA-256 of `subject_type` + sorted ids + `prompt_version` + `model_id`. Changing the prompt or model produces a different key rather than silently reusing stale output (spec §11).
- **Staleness is detected by `inputs_fingerprint`**, a SHA-256 over member state. `final_score` is rounded to 1 decimal before hashing so float representation noise cannot cause spurious invalidation (spec §14.2).
- **`subject_ids` deliberately has no foreign key.** A synthesis must survive a member's deletion as a historical record; the fingerprint catches staleness (spec §11).
- **Retracted members are surfaced, not hidden.** `retracted_member_indices` is populated from `Paper.is_retracted` and rendered as a warning (spec §11).
- Everything is gated behind `SYNTHESIS_ENABLED`, default `false`.
- Run tests as `arch -x86_64 /Users/matthewhagy/Athena/.venv/bin/pytest` from the repo root; the venv's `pydantic_core` is x86_64-only. A `.env` with `DATABASE_URL` must exist.

## Scope note

This plan covers the **comparison synthesis** on the Compare page — spec §14.1's evidence-composition gauge is a separate surface with its own threshold rules and is deliberately excluded, so this plan delivers one coherent, shippable panel rather than two half-built ones.

```python
import hashlib
import uuid
from dataclasses import dataclass
from datetime import datetime

# Bump whenever the prompt text or the tool schema changes. It is part of the cache
# key, so a bump retires every cached narrative rather than mixing prompt generations.
SYNTHESIS_PROMPT_VERSION = "v1"


@dataclass(frozen=True)
class MemberState:
    member_id: uuid.UUID
    scored_at: datetime | None
    final_score: float | None
    evidence_tier: str | None
    is_retracted: bool


def compute_cache_key(
    subject_type: str, subject_ids: list[uuid.UUID], prompt_version: str, model_id: str
) -> str:
    sorted_ids = ",".join(sorted(str(i) for i in subject_ids))
    payload = f"{subject_type}|{sorted_ids}|{prompt_version}|{model_id}"
    return hashlib.sha256(payload.encode("utf-8")).hexdigest()


def compute_inputs_fingerprint(members: list[MemberState]) -> str:
    lines = []
    for member in sorted(members, key=lambda m: str(m.member_id)):
        scored_at = member.scored_at.isoformat() if member.scored_at else "none"
        # Rounded to 1 decimal, matching the precision compute_base_score returns
        # (evidence_engine/scoring/formula.py:49), so float noise cannot invalidate.
        score = "none" if member.final_score is None else f"{round(member.final_score, 1)}"
        tier = member.evidence_tier or "none"
        lines.append(f"{member.member_id}|{scored_at}|{score}|{tier}|{member.is_retracted}")
    return hashlib.sha256("\n".join(lines).encode("utf-8")).hexdigest()
```

```python
from dataclasses import dataclass, field

# At least 60% of surviving claims must carry a resolvable citation, or the whole
# synthesis is rejected. An ungrounded narrative is worse than no narrative.
MIN_CITATION_DENSITY = 0.6


@dataclass
class ValidationResult:
    ok: bool
    failure_reason: str | None = None
    narrative: str | None = None
    claims: list[dict] = field(default_factory=list)
    disagreements: list[dict] = field(default_factory=list)
    strength_ranking: list[int] = field(default_factory=list)


def _valid_indices(values, member_count: int) -> list[int]:
    if not isinstance(values, list):
        return []
    return [v for v in values if isinstance(v, int) and 0 <= v < member_count]


def validate_response(raw: dict | None, member_count: int) -> ValidationResult:
    """Structural + grounding validation. Nothing is stored or shown unless this returns ok."""
    if raw is None:
        return ValidationResult(ok=False, failure_reason="llm_unavailable")

    narrative = raw.get("narrative")
    if not isinstance(narrative, str) or not narrative.strip():
        return ValidationResult(ok=False, failure_reason="no_valid_claims")

    raw_claims = raw.get("claims")
    if not isinstance(raw_claims, list) or not raw_claims:
        return ValidationResult(ok=False, failure_reason="no_valid_claims")

    claims: list[dict] = []
    for entry in raw_claims:
        if not isinstance(entry, dict):
            continue
        text = entry.get("text")
        if not isinstance(text, str) or not text.strip():
            continue
        claims.append({"text": text.strip(), "citations": _valid_indices(entry.get("citations"), member_count)})

    if not claims:
        return ValidationResult(ok=False, failure_reason="no_valid_claims")

    cited = sum(1 for c in claims if c["citations"])
    if cited / len(claims) < MIN_CITATION_DENSITY:
        return ValidationResult(ok=False, failure_reason="citation_density")

    disagreements = []
    for entry in raw.get("disagreements") or []:
        if not isinstance(entry, dict):
            continue
        indices = _valid_indices(entry.get("indices"), member_count)
        description = entry.get("description")
        # A disagreement names exactly two members; anything else is unusable.
        if len(indices) != 2 or not isinstance(description, str) or not description.strip():
            continue
        disagreements.append({"indices": indices, "description": description.strip()})

    seen: set[int] = set()
    strength_ranking = []
    for idx in _valid_indices(raw.get("strength_ranking"), member_count):
        if idx not in seen:
            seen.add(idx)
            strength_ranking.append(idx)

    return ValidationResult(
        ok=True,
        narrative=narrative.strip(),
        claims=claims,
        disagreements=disagreements,
        strength_ranking=strength_ranking,
    )
```

    study_type: str | None
    abstract: str | None
    is_retracted: bool


SYNTHESIS_TOOL = {
    "name": "record_synthesis",
    "description": "Record a grounded synthesis of the supplied studies.",
    "input_schema": {
        "type": "object",
        "properties": {
            "narrative": {
                "type": "string",
                "description": "2-4 sentences comparing the studies. No claim without a citation.",
            },
            "claims": {
                "type": "array",
                "description": "Each factual claim, with the indices of the studies supporting it.",
                "items": {
                    "type": "object",
                    "properties": {
                        "text": {"type": "string"},
                        "citations": {"type": "array", "items": {"type": "integer"}},
                    },
                    "required": ["text", "citations"],
                },
            },
            "disagreements": {
                "type": "array",
                "description": "Pairs of studies that conflict, and how.",
                "items": {
                    "type": "object",
                    "properties": {
                        "indices": {"type": "array", "items": {"type": "integer"}},
                        "description": {"type": "string"},
                    },
                    "required": ["indices", "description"],
                },
            },
            "strength_ranking": {
                "type": "array",
                "description": "Study indices ordered strongest evidence first.",
                "items": {"type": "integer"},
            },
        },
        "required": ["narrative", "claims", "disagreements", "strength_ranking"],
    },
}


def build_prompt(members: list[MemberInput]) -> str:
    blocks = []
    for index, member in enumerate(members):
        abstract = (member.abstract or "").strip()[:MAX_ABSTRACT_CHARS] or "(no abstract available)"
        retracted = " [RETRACTED]" if member.is_retracted else ""
        blocks.append(
            f"[{index}] {member.title}{retracted}\n"
            f"    evidence tier: {member.tier or 'not yet scored'}\n"
            f"    study type: {member.study_type or 'unknown'}\n"
            f"    abstract: {abstract}"
        )
    body = "\n\n".join(blocks)

    # The instructions below are the hallucination guardrails. The validator enforces
    # them independently -- this text only improves the odds of a compliant response.
    return (
        "You are comparing research studies for a researcher who will act on your summary.\n\n"
        "Rules you must follow:\n"
        "- Use ONLY the studies listed below. Never introduce a study, statistic, or "
        "finding that does not appear in them.\n"
        "- Every claim must cite the indices of the studies supporting it. A claim you "
        "cannot cite must be omitted entirely.\n"
        "- Do not state or imply causation unless a study listed below does.\n"
        "- Treat a study marked [RETRACTED] as unreliable and say so if you reference it.\n"
        "- Rank by evidence strength using study design and tier, not by how interesting "
        "the finding is.\n"
        "- If the studies do not support a meaningful comparison, say so plainly rather "
        "than manufacturing agreement.\n\n"
        f"Studies:\n\n{body}\n\n"
        "Record your synthesis with the record_synthesis tool."
    )
```

import time

from evidence_engine.llm.client import call_forced_tool
from synthesis.prompt import SYNTHESIS_TOOL, MemberInput, build_prompt
from synthesis.validation import ValidationResult, validate_response

MAX_TOKENS = 1500


def generate_synthesis(members: list[MemberInput], call=None) -> tuple[ValidationResult, int]:
    """Call the model once and validate the response. Never raises on model failure."""
    call = call or call_forced_tool
    prompt = build_prompt(members)

    started = time.monotonic()
    try:
        raw = call(prompt, SYNTHESIS_TOOL, MAX_TOKENS)
    except Exception:
        # call_forced_tool already swallows provider errors and returns None, but a
        # transport failure below it must not propagate into the request path.
        raw = None
    latency_ms = int((time.monotonic() - started) * 1000)

    return validate_response(raw, member_count=len(members)), latency_ms
```

```python
import uuid
from datetime import datetime, timedelta

from sqlalchemy import select
from sqlalchemy.orm import Session

from evidence_engine.config import get_settings
from evidence_engine.db.models import Paper, Score
from synthesis.generate import generate_synthesis as default_generate
from synthesis.keys import (
    SYNTHESIS_PROMPT_VERSION,
    MemberState,
    compute_cache_key,
    compute_inputs_fingerprint,
)
from synthesis.models import ComparisonSynthesis, SynthesisGeneration
from synthesis.prompt import MemberInput

COOLDOWN_MINUTES = 60


def _synthesis_enabled() -> bool:
    return get_settings().synthesis_enabled


def _load_papers(session: Session, subject_ids: list[uuid.UUID]) -> list[Paper]:
    ordered_ids = sorted(subject_ids, key=str)
    papers = []
    for member_id in ordered_ids:
        paper = session.get(Paper, member_id)
        if paper is None:
            raise ValueError(f"Paper {member_id} not found")
        papers.append(paper)
    return papers


def _score_for(session: Session, paper_id: uuid.UUID) -> Score | None:
    """A pending score is not a score.

    Score rows are created with is_pending=True before scoring completes, carrying
    column defaults (evidence_tier='speculative', final_score=0.0). Treating those
    as real would tell the model a paper is speculative evidence when it is simply
    unscored -- the same misrepresentation webapp/search_index.py guards against.
    """
    score = session.execute(select(Score).where(Score.paper_id == paper_id)).scalar_one_or_none()
    return None if score is not None and score.is_pending else score


def get_or_create_synthesis(
    session: Session,
    subject_type: str,
    subject_ids: list[uuid.UUID],
    user_id: uuid.UUID | None = None,
    generate=None,
    now: datetime | None = None,
) -> ComparisonSynthesis | None:
    """Return a cached synthesis, or generate one. None when the feature is disabled."""
    if not _synthesis_enabled():
        return None

    now = now or datetime.utcnow()
    generate = generate or default_generate

    papers = _load_papers(session, subject_ids)
    ordered_ids = [p.id for p in papers]

    states, inputs, retracted = [], [], []
    for index, paper in enumerate(papers):
        score = _score_for(session, paper.id)
        states.append(
            MemberState(
                member_id=paper.id,
                scored_at=score.scored_at if score else None,
                final_score=score.final_score if score else None,
                evidence_tier=score.evidence_tier.value if score and score.evidence_tier else None,
                is_retracted=bool(paper.is_retracted),
            )
        )
        inputs.append(
            MemberInput(
                title=paper.title,
                tier=score.evidence_tier.value if score and score.evidence_tier else None,
                study_type=score.study_type.value if score and score.study_type else None,
                abstract=paper.abstract,
                is_retracted=bool(paper.is_retracted),
            )
        )
        if paper.is_retracted:
            retracted.append(index)

    model_id = get_settings().anthropic_model
    cache_key = compute_cache_key(subject_type, ordered_ids, SYNTHESIS_PROMPT_VERSION, model_id)
    fingerprint = compute_inputs_fingerprint(states)

    existing = session.execute(
        select(ComparisonSynthesis).where(
            ComparisonSynthesis.cache_key == cache_key,
            ComparisonSynthesis.superseded_at.is_(None),
        )
    ).scalar_one_or_none()

    if existing is not None:
        if existing.inputs_fingerprint == fingerprint:
            if existing.status == "ready":
                return existing
            # Failed: honour the cooldown so a broken input set cannot be retried in a loop.
            if existing.cooldown_until and existing.cooldown_until > now:
                return existing
        existing.superseded_at = now
        session.flush()

    result, latency_ms = generate(inputs)

    row = ComparisonSynthesis(
        cache_key=cache_key,
        subject_type=subject_type,
        subject_ids=ordered_ids,
        inputs_fingerprint=fingerprint,
        status="ready" if result.ok else "failed",
        narrative=result.narrative if result.ok else None,
        claims=result.claims if result.ok else [],
        disagreements=result.disagreements if result.ok else [],
        strength_ranking=result.strength_ranking if result.ok else [],
        retracted_member_indices=retracted,
        failure_reason=None if result.ok else result.failure_reason,
        cooldown_until=None if result.ok else now + timedelta(minutes=COOLDOWN_MINUTES),
        model_id=model_id,
        prompt_version=SYNTHESIS_PROMPT_VERSION,
        generated_at=now,
    )
    session.add(row)
    session.flush()

    session.add(
        SynthesisGeneration(
            synthesis_id=row.id,
            user_id=user_id,
            member_count=len(inputs),
            outcome=row.status,
            latency_ms=latency_ms,
        )
    )
    session.flush()
    return row
```

def _synthesis_out(row) -> dict:
    return {
        "id": str(row.id),
        "status": row.status,
        "narrative": row.narrative,
        "claims": row.claims,
        "disagreements": row.disagreements,
        "strength_ranking": row.strength_ranking,

        "failure_reason": row.failure_reason,
        "subject_ids": [str(i) for i in row.subject_ids],

@app.post("/synthesis/papers")
def synthesis_papers_endpoint(payload: dict, db: Session = Depends(get_db)) -> dict:
    raw_ids = payload.get("paper_ids") or []
    if not raw_ids or len(raw_ids) > MAX_SYNTHESIS_MEMBERS:
        raise HTTPException(
            status_code=422,
            detail=f"paper_ids must contain between 1 and {MAX_SYNTHESIS_MEMBERS} ids",
        )
    try:
        paper_ids = [uuid.UUID(str(i)) for i in raw_ids]
    except ValueError as exc:
        raise HTTPException(status_code=422, detail="paper_ids must be UUIDs") from exc

    user_id = payload.get("user_id")
    try:
        row = get_or_create_synthesis(
            db, "paper", paper_ids, user_id=uuid.UUID(user_id) if user_id else None
        )
    except ValueError as exc:
        raise HTTPException(status_code=404, detail=str(exc)) from exc

    if row is None:
        raise HTTPException(status_code=503, detail="Synthesis is not enabled")
    return _synthesis_out(row)

- [ ] **Step 5: Write `src/components/SynthesisPanel.tsx`**

```tsx
import { useSynthesis } from "../api/hooks";
import { useIdentity } from "../identity/identity";

export function SynthesisPanel({ paperIds }: { paperIds: string[] }) {
  const { userId } = useIdentity();
  const synthesis = useSynthesis();
  const result = synthesis.data;

  return (
    <section className="mb-6 rounded-lg border border-hairline bg-surface-container-lowest p-4">
      <div className="mb-3 flex items-center justify-between">
        <p className="text-xs font-semibold uppercase tracking-wider text-on-surface-variant">
          AI comparison synthesis
        </p>
        <button
          onClick={() => synthesis.mutate({ paperIds, userId })}
          disabled={synthesis.isPending || paperIds.length === 0}
          className="rounded bg-secondary px-3 py-1.5 text-xs font-semibold text-on-secondary disabled:opacity-50"
        >
          {synthesis.isPending ? "Generating…" : "Generate synthesis"}
        </button>
      </div>

      {synthesis.isError && (
        <p className="text-sm text-error">
          Synthesis is not available right now. Try again later.
        </p>
      )}

      {result?.status === "failed" && (
        <p className="text-sm text-on-surface-variant">
          Couldn't produce a grounded summary for these studies. Every claim has to be
          traceable to one of them, and this comparison didn't meet that bar.
        </p>
      )}

      {result?.status === "ready" && (
        <>
          {result.retracted_member_indices.length > 0 && (
            <p className="mb-2 rounded border border-error/40 p-2 text-xs text-error">
              This comparison includes {result.retracted_member_indices.length} retracted
              {result.retracted_member_indices.length === 1 ? " study" : " studies"}.
            </p>
          )}
          <p className="mb-3 font-serif text-sm leading-relaxed text-on-surface">{result.narrative}</p>
          <ul className="space-y-1">
            {result.claims.map((claim, i) => (
              <li key={i} className="text-xs text-on-surface-variant">
                {claim.text}{" "}
                <span className="text-secondary">
                  [{claim.citations.map((c) => c + 1).join(", ")}]
                </span>
              </li>
            ))}
          </ul>
          <p className="mt-3 text-xs text-on-surface-variant">
            Generated from the {result.subject_ids.length} studies compared here. Bracketed
            numbers refer to their position above.
          </p>
        </>
      )}
    </section>
  );
}
```

## Self-Review

**Spec coverage.** Tasks map to the comparison-synthesis half of the B spec: §11's `comparison_syntheses` and `synthesis_generations` (Task 1), §11's cache key and §14.2's fingerprint including the float-stability rule (Task 2), §14.3's citation-density check and the three `failure_reason` values (Task 3), the prompt and forced-tool contract built on the existing `call_forced_tool` (Task 4), caching, supersession, and cooldown (Task 5), the HTTP surface (Task 6), and the panel that fills the placeholder A left on the Compare page (Task 7).

**Deliberately excluded, with reasons.** §14.1's evidence-composition gauge is a different surface with its own hiding threshold — folding it in would double the plan's size and delay the panel that carries most of the value; it belongs in its own plan. `synthesis_rate_windows` (spec §11) is omitted because this plan's cooldown plus the content-addressed cache already bound cost: a repeated request for the same members costs nothing, and a failing set is locked out for an hour. Per-user rate limiting should be added with the shared limiter the roadmap identifies as cross-cutting (§4), not built single-use here. Topic syntheses (`subject_type='topic'`) are modeled throughout but only the paper endpoint ships, because the Compare page's topic mode already renders `ConsensusSnapshot` text.

**Open question carried forward.** OQ-B-003 (token accounting) is unresolved: `input_tokens` and `output_tokens` exist on `synthesis_generations` but nothing populates them, because `call_forced_tool` discards `response.usage` (`evidence_engine/llm/client.py:20-28` returns only `block.input`). Capturing usage means changing a shared helper that `evidence_engine/consensus/synthesizer.py` also calls. The columns are nullable so this can be added later without a migration; until then, cost analysis uses `member_count` and `latency_ms` as proxies.

**Placeholder scan.** No TBD/TODO markers; every code step carries complete code; every test carries real assertions.

**Type consistency.** `MemberState` fields match between Task 2's definition and Task 5's construction. `MemberInput` matches between Tasks 4 and 5. `ValidationResult` fields match between Task 3 and its use in Tasks 4 and 5. `generate_synthesis(members, call=None) -> (ValidationResult, int)` is called by Task 5 with exactly that shape. The `SynthesisResult` TypeScript interface mirrors `_synthesis_out` field for field.

**A defect this plan deliberately avoids.** `Score` rows are created with `is_pending=True` before scoring completes and carry column defaults — `evidence_tier='speculative'`, `final_score=0.0`. Sub-project A shipped exactly this bug: `_paper_out` serialized those defaults, so unscored papers rendered as speculative evidence, and it was caught only by the final whole-branch review (fixed in `93273a9`). B reads `Score` directly and would reintroduce it in a worse place — telling the model a paper is speculative evidence when it is merely unscored, then citing that narrative to a researcher. `_score_for` in Task 5 treats a pending score as no score, matching `webapp/search_index.py`'s existing rule. This is the one place in the plan where a reviewer should check the behavior rather than the code.
